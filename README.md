# WARRANT OS — 根命名空间

位置不是约定,是推导:**地址 = 内容哈希 × 血统**。
没有"应用数据"这个类别;权限的根是意图(令状),不是身份。

## 八个顶级命名空间

| 目录 | 角色 | 主权 | 寿命 |
|---|---|---|---|
| `kernel/` | 宪法内核 · 规则与封印 | 系统 | 永封,双签才可换 |
| `ledger/` | 总账 · 一切令状事件 | 系统 | 只增,不可篡改 |
| `warrant/` | 令状 · 有寿命的意志 | 用户 | 随意图生灭 |
| `vault/` | 国库 · 用户数据 | 用户 | 随血统存续 |
| `mind/` | 代理记忆 · AI 本体 | 用户委托 | 可整体更换 |
| `registry/` | 服务名录 · 只注册不安装 | 公共 | 可重建 |
| `run/` | 瞬态层 · 飞地与能力 | 无主 | 重启即空 |
| `mesh/` | 联邦 · 跨设备网格 | 用户 | 随锚点迁移 |

## 重启不变量

整机状态 = `kernel` + `ledger` + `vault` + `mind` + `warrant/standing`。
其余全部可重建。重启语义上是一次全网格重铸。

## 删除语法

删除不是操作,是语法:吊销血统 → 派生地址不可达 → 空间回收。

## 技术规格

- `spec/` — Rust 类型定义 crate(类型即规格:编译通过 ≡ 规格自洽)
  - `crypto` `lineage` `warrant` `capability` `ledger` `kernel` `vault` `mesh` `registry` `run` `mind`
  - `cargo check` 验证
- `warrant-os-spec/` — 技术规格书 HTML(架构图、状态机、协议规范)
