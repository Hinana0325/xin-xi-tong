# /kernel — 宪法内核

哑底座:确定性执行、形式化验证、无智能、不联网。
它不裁决、不协商,只验证指令是否携带合法签名。
**正因为不思考,才不能被说服。**

## 主权与寿命

- 主权:系统(双最高之一,管资源与完整性)
- 寿命:永封。引导即验签 `constitution.sig`

## 内容

- `constitution.sig` — 规则集的默克尔根签名,ed25519
- `rules/mint.rules` — 铸造边界:能力四属性不得超 expansive 于母令状
- `rules/dual-sign.rules` — 双签门槛:权限语义变更需用户+系统联签
- `rules/revocation.rules` — 吊销级联:血统一灭,派生全灭

## 铁律

1. 内存安全修复可自动应用(须附语义不变性证明)
2. 权限语义变更必须双签,无例外
3. AI 可以呈报到嘴皮磨破,铸造厂只验签名,不听论证
