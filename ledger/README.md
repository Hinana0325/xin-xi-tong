# /ledger — 总账

系统的心跳记录:令状签发、能力铸造、结果核销、吊销级联,
一切事件按链式哈希追加于此。

## 主权与寿命

- 主权:系统
- 寿命:只增(append-only)。条目写定后不可修改、不可删除

## 内容

- `GENESIS` — 创世块,prev 为全零哈希,宪法封印事件
- `entries/NNNN.entry` — 顺序编号的事件条目,每条含 prev 指针 + 签名

## 与日志的区别

传统 /var/log 是给运维看的;这里日志升级为**总账**——
血统链的事实地基,审计时逐环回放:

> 哪张令状 → 铸了什么能力 → 交给了哪个服务 → 结果是否偏差超阈值

销毁的令状不删除记录,核销后写入此处。
空间回收由血统吊销触发,账本本身永不收缩。
