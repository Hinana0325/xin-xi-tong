# /registry — 服务名录

软件不安装,只注册。能力按需召唤,代码内容寻址。

## 主权与寿命

- 主权:公共(名录开放,准入验签)
- 寿命:可重建。名录丢了从网络重取即可

## 子目录

- `manifests/` — 服务注册清单:能力声明、厂商签名、飞地类型、计费方式
- `cache/` — 内容寻址的代码缓存(已 gitignore,可随时清空重建)

## 与传统安装的区别

| 传统 | 本系统 |
|---|---|
| 安装 = 复制进 /usr /opt,永久驻留 | 注册 = 挂一条 manifest,零字节落盘 |
| 卸载残留 AppData / ~/.config | 类别消亡,无残留可言 |
| 权限随 App 永久持有 | 能力寿命 = 意图寿命 |

服务向**系统**请求权限,不面对用户;
拿到的是目的受限数据视图,处理完即焚。
