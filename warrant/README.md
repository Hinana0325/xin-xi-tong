# /warrant — 令状

权限的原子单位不是身份,是**被签发的一次意图**。
没有令状,系统拒绝铸造,服务拿不到能力,AI 寸步难行。

## 主权与寿命

- 主权:用户(意志唯一来源,硬件密钥签名)
- 寿命:令状寿命 = 意图寿命。任务完成即核销

## 子目录

- `live/` — 活跃令状:一次性意图,TTL 到点自毁
- `standing/` — 常设令状:持续性意图(物联网),须持续证明存活

## 四属性(每张令状必填)

| 属性 | 含义 |
|---|---|
| scope | 能碰哪些数据、哪些服务 |
| budget | 次数/流量/算力额度,耗尽即止 |
| ttl | 时限,到点自毁 |
| revocation_handle | 吊销句柄,级联全网生效 |

## 铁律

**意图必须可枚举(数据·服务·预算三件套),终值不可入状。**
"延续文明""最大化幸福""保护用户"永远不能成为令状内容——
不可枚举的意图一旦入状,解释权就升格为主权。
