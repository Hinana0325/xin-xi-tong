# /run — 瞬态层

无主之地:正在进行的执行。重启即空,内容永不持久化。

## 主权与寿命

- 主权:无主(运行时由内核托管)
- 寿命:瞬态。断电 = 全部消失,这是特性不是缺陷

## 子目录

- `enclaves/` — 服务飞地:临时沙箱,用后即焚
- `capabilities/` — 已铸造的能力令牌:范围/时限/预算/血统

## 为什么 gitignore

重启在语义上是一次**全网格重铸**——
能力全部重新铸造,而不是从盘上恢复。
攻击者在持久层植入的任何东西,活不过一次断电。

能力令牌从这里出生,在这里耗尽预算,在这里自毁。
持久层(ledger)只记账本,不记令牌本身。
