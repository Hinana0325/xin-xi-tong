# /mesh — 联邦

跨设备网格:权限跟着人走,不跟着设备走。
手表说的话、手机签的状、网关铸的能力,是同一条血统链的几段。

## 主权与寿命

- 主权:用户(签名锚持有者)
- 寿命:随锚点迁移。换手机 = 新锚凭硬件密钥接管全部常设令状

## 子目录

- `peers/` — 已知设备与心跳(端点角色、降级预算、对账策略)
- `anchors/` — 签名锚与迁移记录(密钥栖所、失联降级策略)

## 端点分级

| 端点 | 内核 | 确认方式 |
|---|---|---|
| 桌面 | 完整内核 | 全量三件套审阅 |
| 移动 | 内核+安全芯片 | 生物识别签名 |
| 穿戴 | 瘦身内核,密钥锚定手机 | 一瞥确认,预算封顶 |
| 物联网 | 网关持内核,端点零智能 | 常设令状+持续证明 |

## 风险备忘

锚点失联超时 → 端点降级为只读+本地预算;
离线铸造自动进入降级预算,回连逐环核销,对不上即吊销整张令状。
